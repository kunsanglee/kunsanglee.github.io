### 연출 (지시 10~14)

- **10 · 장면 2**: 카드가 접혀 나오는 6.9초부터 0.6초 동안 코드베이스 트리와 DB 원통을 30% 밝기로 낮춘다(3차는 38%). 두 그림의 이름표도 7.1초부터 35% 로 흐려진다. 가로 화면에서는 카드를 말풍선 바로 아래로 옮겨 DB 와 떨어뜨렸다. 세로 화면의 카드는 3차부터 말풍선 아래에 있었다. 카드가 떠나는 시각을 8.2초에서 9.0초로 늦춰, 7.8초와 8.95초 캡처에서 두 크기 모두 카드가 또렷하다(1.15초 이상). 장면 길이는 9.3초에서 10.1초로, 스크롤 칸은 화면 높이 1.5배에서 1.65배로 늘었다(전체 9.8배 → 9.95배).
- **11 · 장면 5**: 동료 빛이 꺼진 뒤 남는 밝기를 11% 에서 1% 로 낮췄다. 7.2초 캡처에서 꺼진 자리 다섯 곳(바늘이 지나는 한 곳 제외)의 밝기를 재면 나머지 고리 선 밝기(중앙값)의 1.32배(1440), 1.24–1.26배(390)로, 희미한 점으로만 남는다. 시계 아래에 주 표시를 더했다. 평일 눈금 다섯 개 뒤에 한 칸을 띄고 주말 눈금 두 개를 두었고, 숫자와 글자는 없다. 금요일 칸이 빛나다가 바늘이 자정을 넘으면 토요일 칸으로 옮겨 가고, 그때부터 주말 두 칸이 켜진 채 남는다. 가로 화면은 주 표시가 글 칸에 닿지 않게 시계를 90% 크기로 그리고 조금 올렸다.

### 영어로 처음 열 때 빈 화면 (지시 15)

- 사전과 언어 적용 코드, 한/EN 버튼 동작을 `<head>` 인라인 스크립트로 옮기고, 3차의 2.5초 타이머를 지웠다.
- 지시는 "DOMContentLoaded 에서 바로 적용" 이었다. 그런데 DOMContentLoaded 는 `defer` 로 받는 site.js·particles.js 가 다 실행된 뒤에 오므로, 두 파일이 늦게 오면 그만큼 화면이 비어 있게 된다. 그래서 본문 맨 끝에 인라인 한 줄(`window.__langInit && window.__langInit();`)을 두어 HTML 을 다 읽은 즉시 적용하고, DOMContentLoaded 는 예비로 남겼다. 같은 일을 두 번 하지 않게 막아 두었다.
- 버튼 동작이 인라인 코드에 있어 site.js 없이도 버튼이 눌린다. 입자 글자는 `fx:lang` 이벤트를 받은 particles.js 가 바꾼다.
- 확인(1440·390, `?lang=en`): 보통, site.js·particles.js 응답을 6초 늦춘 경우, site.js 를 막은 경우 모두 0.5초 시점에 `<html lang="en">`, 화면 보임, 영어 글, EN 버튼 눌림 상태였다. 세 경우 모두 한 → EN 을 눌러 언어가 바뀌었고, 본문까지 내려 글이 보였다.
- particles.js 가 6초 늦으면 그동안 무대는 비어 있고 글과 탭만 영어로 보이다가, 6초가 지나면 읽는 판(큰 이름)으로 바뀐다. 이 6초 대체는 3차부터 있던 시작 보호다.

색은 F 의 점토 주황 `#eb663d` · 호박 `#ffa84d` · 크림 `#f6ecdf` 과 흰 코어, 바탕 `#0a0807` 을 쓴다. 입자 엔진의 크림은 `[1.00, 0.93, 0.83]`(약 `#ffedd4`)로 글자의 크림보다 조금 더 노랗다. 이 밖에 읽는 판의 큰 이름과 서명 글자에는 호박과 크림 사이의 복숭아색 `#ffd3a3` 을, Email 버튼에 마우스를 올렸을 때의 버튼 바탕과 글을 선택했을 때의 글자에는 흰색 `#fff` 를 쓴다(`?fps` 표시의 글자 그림자 `#000` 은 개발용). 사람은 호박색 빛, 에이전트는 사람과 같은 크기의 크림 빛(흰 코어)이다. 코드베이스·데이터베이스는 점토 주황 선, 할 일 카드와 규칙 줄은 크림, 장면 8 의 상자는 호박·크림 선이고, 혜성이 벽을 넘는 순간 그 벽만 점토 주황으로 번쩍인다. 그림 속 개수(사람·점·카드·혜성·눈금)에는 숫자 라벨을 붙이지 않았다. 장면 8 의 상자는 실제 외부 연동 폴더 수대로 9개다.

## 두 언어

- 첫 언어: `?lang=ko|en` → 전에 고른 언어(localStorage, try/catch) → `navigator.language` 가 ko 로 시작하면 한국어, 아니면 영어.
- 오른쪽 위 `한 / EN` 버튼(키보드로 누를 수 있음, `aria-pressed`)을 누르면 `<html lang>`, 문서 title, 모든 글, aria 라벨, 입자 위 라벨이 바뀌고 선택을 저장한다. 주소에 `?lang=` 이 있으면 그 값도 `history.replaceState` 로 맞춘다.
- 전환하면 지금 장면의 입자가 흩어졌다가 새 언어 모양으로 다시 모인다(장면 6 은 "30분" ↔ "30 min", 글 칸 크기가 바뀌는 장면은 그에 맞춘 배치로).
- 한글 입자 글자는 Pretendard 를 받은 뒤 샘플링한다. 글꼴 CSS 를 받은 뒤 최대 2.5초 기다리고, CSS 가 늦으면 시작 2.6초 뒤부터 있는 글꼴로 샘플링한다.
- 정적 HTML 이 한국어라서, 영어로 열면 HTML 을 다 읽어 영어를 넣을 때까지 화면을 감춘다. 외부 스크립트를 기다리지 않는다.
- meta description·og 는 정적 HTML 의 한국어이고 전환해도 바꾸지 않는다(검색·공유 미리보기는 한국어로 나간다).

## 상호작용과 보호 장치

- 스크롤: 장면을 넘기는 유일한 방법(휠·트랙패드·터치·키보드).
- 아래 탭 9개: 누르면 그 장면 칸으로 간다. 탭 밑줄이 장면 진행도를 보여 준다. 본문에 들어가면 폭 1180px 이상 화면의 머리말에 본문 절 목록이 나온다.
- 포인터: 움직이면 입자가 밀려나고, 짧게 누르면 그 자리에서 흩어졌다가 같은 모양으로 돌아온다. 링크·버튼·탭·언어 버튼을 누를 때는 흩어지지 않는다.
- 주소 옵션: `?fps`(fps·입자 수·dpr 표시), `?n=숫자`(입자 수, 8,000~60,000), `?nofx`(입자 없이 읽는 판), `?capture`(캡처 스크립트가 시간을 진행), `?lang=ko|en`. `?aek` · `?aep` 는 자동 노출 조정용 개발 옵션이다.
- 시작 보호: 6초 안에 엔진이 뜨지 않으면 읽는 판으로 돌아간다. WebGL 컨텍스트를 잃었다 되찾으면 새로고침한다. 그리는 해상도는 dpr 2 까지이고, 21ms 를 넘는 프레임이 계속 쌓이면(누적 45 초과) dpr 1 로 내린다. 짧은 변이 560px 보다 작거나 터치 화면이면 입자를 32,000개(아니면 40,000개)로 둔다.
- `prefers-reduced-motion: reduce` 이면 입자를 켜지 않고 읽는 판을 보여 준다(언어 전환은 그대로 된다).

## 지시·정본과 다르게 한 것

- 15번: 지시는 "DOMContentLoaded 에서 적용" 이었지만, 본문 끝 인라인 한 줄에서 적용하고 DOMContentLoaded 는 예비로 두었다. 이유는 위 "지시 15" 에 적었다.
- 8번: 터치 화면용 KO 조작 안내도 같은 말투로 바꿨다(지시에 없던 변경).
- 11번: 지시는 시계 둘레 밖에 주말 표시를 두라는 것이었다. 주말 눈금만 두면 무엇을 뜻하는지 읽기 어려워, 시계 아래에 평일 다섯 칸과 주말 두 칸을 함께 두고 사이를 띄워 나눴다.

"이어서 말한 스레드에는 …" 의 영어 "Follow-ups include …" 는 2차에 영어가 없어 3차에 내가 옮긴 것이다.

## 약한 점

- 실제 아이폰·안드로이드·Safari·Firefox 에서는 돌려 보지 못했다. 모바일 60fps 는 같은 노트북에서 모바일 화면을 흉내 낸 값이다.
- 장면 2 가 10.1초로 길어졌다. 합류 · 부름 · 빛줄기 · 답 · 카드 다섯 동작이 들어 있어, 스크롤을 빨리 내리면 카드가 나오기 전에 다음 장면으로 넘어간다.
- 장면 5 의 꺼진 동료 자리는 완전히 사라지지 않고 고리 선보다 1.2–1.3배 밝은 희미한 점으로 남는다. 지시의 "고리 선 밝기까지" 에 가깝지만 똑같지는 않다.
- 장면 5 의 주 표시는 눈금만 있고 글자가 없다. 평일과 주말은 간격으로만 나뉘어 있어, 처음 보는 사람이 한 주로 읽지 못할 수 있다.
- 장면은 칸에 들어갈 때부터 시간으로 재생된다. 아주 빨리 스크롤하면 장면이 끝나기 전에 다음 장면으로 넘어간다.
- 영어로 처음 열면 HTML(약 60KB)을 다 받을 때까지 화면이 비어 있다. 외부 스크립트는 기다리지 않지만, HTML 자체가 느리게 오는 경우는 재지 않았다.
- particles.js 가 늦게 오면 최대 6초 동안 무대가 비어 있다(글과 탭은 보인다).
- 영상은 CSS 전환을 손으로 1/30초씩 밀어 찍어서, 글자가 뜨는 타이밍이 실제 브라우저와 조금 다를 수 있다.
- `shots/` 가 146MB 다. 배포할 때는 빼는 편이 낫다.
