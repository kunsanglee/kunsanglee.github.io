## 콘셉트

정체성 문장 "AI 에이전트를 만들고, 그 에이전트가 일하기 좋은 코드 구조를 설계합니다"의 두 부분을 장면 순서로 보여 준다. 장면 2~7 은 에이전트가 동료 사이에 들어와 일하는 모습(불리면 찾아 답함, 말뜻을 읽음, 지난 대화를 찾음, 근무 시간 밖에도 답함, 사람의 일을 끊지 않음, 리뷰에서 승인된 것을 규칙으로 남김)이고, 장면 8 은 그 에이전트가 일하는 코드 구조, 장면 9 는 다음 에이전트를 같이 만들자는 연결이다. 장면 2 의 동료 고리가 장면 5 와 9 에 다시 나와 처음과 끝을 잇는다. 크게 움직이는 장면은 4(성운 안으로 날아들어 별자리가 켜짐)와 8(카메라가 3D 상자 9개 둘레를 돎) 두 곳에 모으고, 5·6 은 조용히 두었다.

색은 F 의 점토 주황 `#eb663d` · 호박 `#ffa84d` · 크림 `#f6ecdf` 과 흰 코어, 바탕 `#0a0807` 만 쓴다. 사람은 호박색 빛, 에이전트는 사람과 같은 크기의 크림 빛(흰 코어)이다. 코드베이스·데이터베이스는 점토 주황 선, 할 일 카드와 규칙 줄은 크림, 장면 8 의 상자는 호박·크림 선이고, 혜성이 벽을 넘는 순간 그 벽만 점토 주황으로 번쩍인다. 그림 속 개수(사람·점·카드·혜성)에는 숫자 라벨을 붙이지 않았다. 장면 8 의 상자는 실제 외부 연동 폴더 수대로 9개다.

## 두 언어

- 첫 언어: `?lang=ko|en` → 전에 고른 언어(localStorage, try/catch) → `navigator.language` 가 ko 로 시작하면 한국어, 아니면 영어.
- 오른쪽 위 `한 / EN` 버튼(키보드로 누를 수 있음, `aria-pressed`)을 누르면 `<html lang>`, 문서 title, 모든 글, aria 라벨, 입자 위 라벨이 바뀌고 선택을 저장한다. 주소에 `?lang=` 이 있으면 그 값도 `history.replaceState` 로 맞춘다.
- 전환하면 지금 장면의 입자가 흩어졌다가 새 언어 모양으로 다시 모인다(장면 6 은 "30분" ↔ "30 min", 글 칸 크기가 바뀌는 장면은 그에 맞춘 배치로).
- 한글 입자 글자는 Pretendard 를 받은 뒤 샘플링한다. 글꼴 CSS 를 받은 뒤 최대 2.5초 기다리고, CSS 가 늦으면 시작 2.6초 뒤부터 있는 글꼴로 샘플링한다.
- 정적 HTML 이 한국어라서, 영어로 열 때는 번역이 적용될 때까지 화면을 감춘다(최대 2.5초).
- meta description·og 는 정적 HTML 의 한국어이고 전환해도 바꾸지 않는다(검색·공유 미리보기는 한국어로 나간다).

## 상호작용과 보호 장치

- 스크롤: 장면을 넘기는 유일한 방법(휠·트랙패드·터치·키보드).
- 아래 탭 9개: 누르면 그 장면 칸으로 간다. 탭 밑줄이 장면 진행도를 보여 준다. 본문에 들어가면 폭 1180px 이상 화면의 머리말에 본문 절 목록이 나온다.
- 포인터: 움직이면 입자가 밀려나고, 짧게 누르면 그 자리에서 흩어졌다가 같은 모양으로 돌아온다. 링크·버튼·탭·언어 버튼을 누를 때는 흩어지지 않는다.
- 주소 옵션: `?fps`(fps·입자 수·dpr 표시), `?n=숫자`(입자 수, 8,000~60,000), `?nofx`(입자 없이 읽는 판), `?capture`(캡처 스크립트가 시간을 진행), `?lang=ko|en`. `?aek` · `?aep` 는 자동 노출 조정용 개발 옵션이다.
- 시작 보호: 6초 안에 엔진이 뜨지 않으면 읽는 판으로 돌아간다. WebGL 컨텍스트를 잃었다 되찾으면 새로고침한다. 그리는 해상도는 dpr 2 까지이고, 21ms 를 넘는 프레임이 계속 쌓이면(누적 45 초과) dpr 1 로 내린다. 짧은 변이 560px 보다 작거나 터치 화면이면 입자를 32,000개(아니면 40,000개)로 둔다.
- `prefers-reduced-motion: reduce` 이면 입자를 켜지 않고 읽는 판을 보여 준다(언어 전환은 그대로 된다). 2차에서는 이 설정을 따르지 않았다.

## 정본과 다르게 한 것

- 집계 설명: 2차 문장 "기간 대부분은 1편의 봇이 답했고, 9월 중순에 지금 구조로 바꿨습니다." 에서 앞 절을 빼고 "9월 중순에 지금 구조로 바꿨습니다." 만 남겼다. 본문 v2 가 끝에 더하라고 한 "기간 대부분(235건 중 211건)은 처음 만든 봇이 답했습니다." 와 같은 말이 두 번 나오기 때문이다. 영어 앞부분(2차 문장 번역)은 2차에 영어가 없어 내가 옮겼다.
- 대표 작업 요점 셋의 EN 설명은 정본에서 콜론 뒤 소문자로 시작하지만, 화면에서는 제목 아래 따로 줄을 두어 첫 글자를 대문자로 썼다.

- JS 를 끈 판은 정적 HTML 이라 한국어로만 보인다.

## 측정

- 렌더러: headless Chrome(Playwright) + ANGLE Metal, Apple M4 Pro. 장면마다 칸에 들어가 장면 길이 + 1.5초(최소 4초) 동안 프레임 간격을 재고, 이어서 60프레임을 GPU 와 동기화하며 따로 쟀다. 마지막에 처음부터 본문까지 이어 스크롤하며 쟀다.

## 약한 점

- 실제 아이폰·안드로이드·Safari·Firefox 에서는 돌려 보지 못했다. 모바일 60fps 는 같은 노트북에서 모바일 화면을 흉내 낸 값이다.
- 장면 2 는 8초 남짓에 합류 · 부름 · 빛줄기 · 답 · 카드 다섯 동작이 들어 있어 빽빽하다. 티켓·PR 카드가 또렷하게 보이는 시간은 1초가 안 된다.
- 장면 8 에서 벽이 번쩍이는 순간은 세로 화면에서 상자가 작아 덜 눈에 띈다.
- 장면은 칸에 들어갈 때부터 시간으로 재생된다. 아주 빨리 스크롤하면 장면이 끝나기 전에 다음 장면으로 넘어간다.
- 영어로 처음 열면 번역이 붙을 때까지(보통 스크립트가 도는 즉시, 최대 2.5초) 화면이 비어 있다.
- 영상은 CSS 전환을 손으로 1/30초씩 밀어 찍어서, 글자가 뜨는 타이밍이 실제 브라우저와 조금 다를 수 있다.
- `shots/` 가 123MB 다. 배포할 때는 빼는 편이 낫다.
