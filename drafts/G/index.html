말뜻을 알아듣는

평소 말투로 부탁하면 모델이 뜻을 읽고 할 일을 고릅니다. 비결정론적인 판단은 모델에, 실행해도 되는지 같은 결정론적인 판단은 코드에 맡겼습니다

기억을 가진 에이전트

에이전트가 듣는 채널의 글을 모두 임베딩으로 쌓아 두고, 뜻이 가까운 지난 대화를 필요할 때 찾아 쓰게 했습니다. 30일 동안 1,111건의 임베딩 비용은 1센트도 되지 않았습니다

언제든, 자리에 없어도

그 일을 아는 사람이 자리에 없어도 답을 받을 수 있게 했습니다. 근무 시간 밖에 올라온 질문 39건도 절반은 99초 안에 첫 답이 달렸습니다

하루 30분, 멈추지 않고

하루 약 30분. 업무 질문이 올 때마다 누군가 확인해 답했다면 들었을 시간입니다. 건당 10분으로 잡으면 15주 동안 약 38시간입니다

리뷰를 바탕으로 발전할 수 있도록

ai-ready. 리뷰와 문서로만 권하던 규칙을 자동 검사로 옮기도록 돕는 오픈소스 도구입니다. 바로잡은 실수도 사람이 승인하면 규칙으로 남아 다음 작업의 기준이 됩니다

01대표 작업 · agent-colleague

Slack 에서 일하는 사내 AI 에이전트

처음 만든 봇을 TypeScript 와 Claude Agent SDK 로 다시 설계했습니다. 여기서는 에이전트에게 무엇을 맡기고 무엇을 막았는지, 코드를 어떻게 고치게 했는지를 적었습니다.

  1. 01

    쓰기는 사람이 답한 뒤에

    티켓 생성 같은 쓰기 도구는 봇이 스레드에 글을 올린 뒤 사람이 답했을 때만 실행되고, 실행 기록을 확인해 같은 요청을 두 번 실행하지 않습니다.

  2. 02

    고친 코드는 리뷰를 거쳐서

    격리된 작업 공간에서 구현하고, 수정 권한이 없는 별도 리뷰 세션이 찾은 문제를 반영한 뒤 봇 전용 브랜치에서만 PR 을 엽니다.

  3. 03

    운영 DB 는 좁게

    개인정보 컬럼을 읽지 못하는 계정으로만 조회하고, 쓰기는 거부하며, 실행 계획으로 비용을 재서 무거운 조회는 사람이 답한 뒤에 실행합니다.

2026년 6월 10일~9월 22일, 팀 코드 질문 채널(오류 분석 비율은 오류 알림 채널)의 Slack 스레드를 직접 센 사내 운영 기록입니다. 9월 16일에 에이전트를 다시 설계했고, 기간 대부분(235건 중 211건)은 처음 만든 봇이 답했습니다. 이어서 말한 스레드에는 되물음과 정정도 섞여 있고, 답이 맞았는지는 따로 재지 않았습니다. 장면의 38시간은 잡담 9건을 뺀 226건에 건당 10분(처리 5분, 원래 일로 돌아오는 데 5분)을 곱한 값입니다. 묻는 쪽이 기다린 시간은 넣지 않았고, 모두 바로 답했다는 가정이라 실제보다 크게 잡혔을 수 있습니다. 하루 30분은 이 38시간을 기간 중 근무일 약 75일로 나눈 값입니다.

03Agent-Friendly Architecture

에이전트가 잘 일할 수 있는 코드 구조

Cursor 의 Lauren Tan 이 영상에서 소개한 Dune 프로젝트 문서의 "작업자 에이전트가 자주 하는 다섯 가지"를 바탕으로 했습니다. 예외를 목록과 개수로 테스트하고 그 목록을 비운 것은 제가 따로 정했습니다.

  1. 외부 연결은 시작 파일 두 곳과 운영 스크립트에서만 만들고, 외부 연동 9개는 서비스별 폴더로 모았습니다.

  2. 구조 규칙은 경계 테스트 52개로 옮겼고(2026-10-05 기준) 예외 목록 6개는 모두 비어 있으며, 비어 있는지도 테스트로 확인합니다.

  3. 리뷰 에이전트가 찾은 우회 13건과 변형 3건을 테스트 사례로 고정했습니다.

  4. PR 과 push 전에 같은 검사를 돌립니다. 결함이 줄었는지는 재지 않았습니다.

04Open Source · MIT

리뷰에서 한 말을 다음 작업의 규칙으로

문서에 적힌 규칙마다 이미 강제되는지 따지고, 사람이 승인한 규칙은 lint·아키텍처 테스트 초안으로 옮겨 문서에는 강제할 수 없는 것만 남기는 오픈소스 도구입니다. 작업 중 바로잡은 실수와 PR 리뷰 댓글도 사람이 승인하면 규칙 초안이나 금지 목록 항목이 됩니다.

1.x 는 문서를 7개 영역 점수로 매겼는데, 강제하지 않는 문서를 더 쓰는 것이 점수를 올리는 가장 쉬운 길이어서 2.0 에서 점수를 없앴습니다.
