# 시안 E — 정책 함수가 보는 화면

`index.html` + `assets/app.js` + `assets/policy-flow.png` + `assets/og-image.png`. 빌드 없이 그대로 올리는 정적 파일입니다. 외부에서 불러오는 것은 Pretendard 글꼴(cdn.jsdelivr.net/npm) 하나이고, 입자·물리·판정은 모두 `app.js` 에 직접 썼습니다(외부 스크립트 0개).

## 콘셉트

이건상의 강점은 판단을 모델에게 맡기면서도 실행 허용은 코드로 정해 둔 설계, 그리고 그것을 1편 봇부터 15주 동안 운영한 기록입니다. 이 시안은 그 설계에서 한 순간을 골라 페이지 전체의 연출 규칙으로 씁니다. 메시지가 정책 함수를 지나는 순간 글의 뜻은 빠지고 누가·언제 썼는지와 실행 기록만 남습니다. 화면에서 보라색 입자는 모델이 읽는 글의 뜻, 비취색은 정책 함수가 보는 사실, 흰 점은 질문 스레드 하나입니다. 첫 화면의 96, 235, 주별 기둥, 세션 고리, 마지막에 떨어지는 점 235개는 모두 같은 입자층이 모양만 바꾼 것입니다. 머리띠의 "정책 함수가 보는 화면" 버튼을 누르면 페이지 전체가 정책 함수가 보는 모습으로 바뀝니다. 훑는 선이 지나간 곳부터 글이 띠로 가려지고 시각·판정만 남으며, 맨 아래 안내 칸에는 이 페이지를 보는 사람의 현재 시각이 "이 페이지를 보는 사람 · 시:분:초" 로 찍힙니다.

## 동작 줄이기

`prefers-reduced-motion` 으로 끄는 것이 없습니다. 이 페이지를 볼 사람의 맥이 동작 줄이기를 켜 둔 상태라는 지시에 따라, 켠 조건에서도 입자·스크롤 장면·물리·훑는 선이 그대로 움직입니다. 대신 깜빡임·번쩍임은 넣지 않았습니다. CSS 애니메이션은 클릭 물결(0.95초 한 번), 첫 화면 안내 점의 2.4초 주기 고리, 판정 글자가 바뀔 때 한 번 떠오르는 효과(0.5초)뿐이고, 입자의 흔들림·회전은 가장 빨라도 초당 0.4회 안팎이고 밝기를 빠르게 바꾸는 효과는 없습니다.

측정: 같은 장면을 0.5초 간격으로 두 번 찍어 바뀐 픽셀 수를 셌습니다(1440x900, `/tmp/e_shoot/motion.mjs`).
